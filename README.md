# 🎓 Student Task Manager

A simple and modern **Student Task Manager** web application built using **Flask, HTML, CSS, and JavaScript**.

This project helps students manage their college assignments and daily tasks in one place. Users can add tasks, set subjects, choose priorities, set due dates, mark tasks as completed, delete tasks, and search through their tasks.

## ✨ Features

- 📋 Add new tasks
- 📚 Select task subject
- 🚦 Set task priority — Low, Medium, High
- 📅 Add due dates
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Search tasks
- 📊 Dashboard with task statistics
- 📱 Responsive design for mobile and desktop
- 🌙 Modern UI with dark mode
- 💾 Task data stored using JSON

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **JavaScript**
- **JSON**
